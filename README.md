# Proof of Work Tracker

A simple HTML + CSS + JavaScript tracker based on the uploaded Proof of Work table.

## Features

- Original data from the provided image is preloaded.
- Add new entries.
- Edit existing entries.
- Update edited entries.
- Remove entries.
- Save data to browser localStorage.
- Data remains available after refreshing the page in the same browser.
- Responsive layout.
- HTML table structure with separate CSS and JavaScript.

## Files

- index.html
- style.css
- script.js

## How to run

Open `index.html` in a browser.

No server or npm installation is required.

## Important

The browser's localStorage is used for saving. If browser site data is cleared, the locally saved changes may be removed.
